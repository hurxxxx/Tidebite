아트 수정 빌드: 24개 10초 측정 구간, 59.7~60.0 FPS, p95 16.92~17.57ms, 최대 65.78ms, 25ms 초과 총 7프레임. 이후 배경의 2048px·원본 비율 임포트가 실제 메타데이터에 적용되도록 임포터 버전을 올려 최종 재빌드했고, 홈과 대형 상어의 열린 턱을 다시 확인했습니다. 최종 재실행 로그는 `TestResults/profile-final-frame-pacing.log`입니다. 미리보기 카메라는 메뉴에서 30Hz로만 렌더링하고 플레이 중 비활성화합니다. 런타임 예외·셰이더 오류는 수집한 Player.log에서 발견되지 않았습니다. 이번 아트 수정의 iOS/Android 빌드·실기기 검증과 온라인 회귀 검사는 미실시이며, 위 네트워크/플랫폼 결과는 이전 검사 기록입니다.

`TestResults/network-2-0ms/report.json`, `TestResults/network-32-0ms/report.json`에 각 클라이언트의 결과가 있습니다. 스냅샷 수는 분할 패킷 수이며 서버 틱 수와 같지 않습니다.

초기 `network-2-75ms` 실행은 Release 빌드에서 FishNet 지연 시뮬레이터가 비활성화되어 있었으므로 **지연/손실 검증 결과로 인정하지 않습니다**. 해당 보고서에 무효 사유를 기록했습니다. 실제 UDP 프록시를 사용하는 `scripts/linux-smoke.py`와 `scripts/udp-proxy.py`를 마련했으며, 네이티브 x86_64 Linux에서 검증해야 합니다. 프록시는 양방향 각각 75ms 지연과 3% 확률의 패킷 손실을 주입합니다.

32개 macOS 프로세스 검증 때 Dock에 테스트 앱이 표시되어 사용자 작업을 방해했습니다. 모두 종료했으며, 이후 다중 macOS 테스트는 `--allow-dock-apps`를 명시하지 않으면 실행되지 않도록 변경했습니다. 컨테이너 테스트도 Apple Silicon에서는 실패하는 검증을 반복하지 않고 시작 전에 안내하도록 했습니다.

출시 전 필요한 실기기 검증: 두 손 동시 터치, 앱 전환 및 화면 잠금, Wi-Fi/모바일 데이터 전환, 실제 인터넷 지연, 장시간 발열/메모리/FPS, 저사양 Android 성능, iOS 서명·권한, Android 배포 서명.
